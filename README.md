# The BLOOM Project — Website v1.5

A responsive static website for The BLOOM Project, ready for GitHub Pages.

## Publish free with GitHub Pages
1. Create a free GitHub account.
2. Create a **public** repository. For the cleanest free URL, name it `YOURUSERNAME.github.io`.
3. Upload **the contents of this folder** (not the ZIP itself) to the repository root. `index.html` must be at the top level.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will publish the site. It may take several minutes.

## Before launch
- Replace `CST, MPH` with the founder's preferred public name/biography when ready.
- Confirm all event details and resource information before public promotion.
- Consider purchasing a custom domain later; it is optional.

## Files
- `index.html` — website content
- `styles.css` — responsive design
- `script.js` — mobile menu + copyright year
- `.nojekyll` — tells GitHub Pages to serve the static files directly
- `assets/` — BLOOM images supplied for the project


## Version 1.6 — Events Calendar
A mobile-friendly Events section has been added with a month selector. October 2026 currently contains the BLOOM exhibition (Oct 1–31) and Opening Day (Oct 17). Add future events by copying an `event-card` in `index.html` and changing its `data-month`, date, title, location, description, and link.
